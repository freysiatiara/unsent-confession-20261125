# Unsent: The Micro-Confession Sprint

A make.fun entry: one two-part micro-confession — a `To:` line naming who
it was meant for, and the unsent message itself, one line written exactly
as it was typed.

## Run

```sh
python3 main.py
```

`main.py` (Python standard library only) writes the confession to
`/output/entry.txt` (or `$ENTRY_OUTPUT`, or `$OUTPUT_DIR/entry.txt`).

## The entry

> To: my sister
>
> I kept the voicemail where you cried about Dad because it's the only time you've ever sounded like a kid again.
